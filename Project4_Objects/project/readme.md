# Forest Adventure

Santosh Khanal

## Project 4: Organize the Structure and Introduce Objects

This project is a simple text-based adventure game.

## File structure

- main.py: starts the game and shows the main menu
- player.py: contains the Player class
- room.py: contains the Room class
- item.py: contains the Item class

## Game idea

The player starts in the forest. The player can move between rooms, collect items, and check the inventory.
