# Forest Adventure

## Author
Santosh Khanal

## Project 5: File Handling

### Description
Forest Adventure is a text-based adventure game written in Python. The player explores different locations, collects items, manages an inventory, and can save and load game progress using file handling.

### Game Features
- Multiple locations (Forest, Cave, and Castle)
- Inventory system
- Item collection
- Save and load game functionality
- Object-oriented programming with classes

### File Structure
- `main.py` - Starts the game and displays the main menu
- `player.py` - Contains the Player class
- `room.py` - Contains the Room class
- `item.py` - Contains the Item class
- `intro.txt` - Contains the introduction text
- `instructions.txt` - Contains the game instructions
- `save_ss.txt` - Save file created when the game is saved

### Requirements
- Python 3.x

### How to Run

```bash
python main.py
```

### How to Play
- Choose **No** to start a new game.
- Choose **Yes** to continue a saved game.
- Move between rooms using the available directions.
- Collect items and check your inventory.
- Save your progress and continue later.
