# Forest Adventure

## Author
Santosh Khanal

## Game Idea and Objective

Forest Adventure is a command-line game about a village with a polluted river. The player explores the Forest, Cave, and Castle to help restore clean water.

## How to Run and Play

Run `Project5_File_Handling/project/main.py` using Python 3 or PyCharm. No external packages are needed.

- Enter **no** to start a new game and provide your name and age.
- Use the numbered menu to move, collect items, and perform actions.
- Choose **4** to check your inventory and progress.
- Choose **5** to save the game.
- Type **lopeta** to quit.
- To load a save, restart the game, enter **yes**, and use the same player name.

## Three Ways to Win

### 1. Repair the Water Filter
- Collect **Tools** in the Forest.
- Collect the **Filter part** in the Cave.
- Go to the Castle and choose **6**.

### 2. Clean Up the Rubbish
- Choose **7** in all three locations.
- Go to the Castle and choose **8**.

### 3. Community Action
- Choose **9** in the Forest to collect evidence.
- Choose **10** at both the Cave and Castle to gain villagers' support.

Completing any one route wins the game.

## Sustainable Development

The game connects to **UN Sustainable Development Goal 6: Clean Water and Sanitation** through equipment repair, responsible rubbish disposal, and community action. Water restoration is simplified for gameplay purposes.
