# Forest Adventure

Sandesh Thapa

## Project 5: File Handling

This is a simple text-based adventure game.

## File structure

- main.py: starts the game and shows the main menu
- player.py: contains the Player class
- room.py: contains the Room class
- item.py: contains the Item class
- intro.txt: contains the introduction text
- instructions.txt: contains the game instructions
- save_playername.txt: created when the player saves the game

## Game idea

The player can move between Forest, Cave, and Castle.
The player can collect items and check the inventory.
The player can save the game and continue later by entering the saved player name.

## How to run

Run main.py.
Choose no to start a new game.
Choose yes to continue a saved game.
